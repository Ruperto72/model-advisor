# Contributing to Model Advisor

Thanks for your interest in improving Model Advisor! Here's how you can help.

## Reporting Issues

Found a case where the skill recommends the wrong model? Open an issue with:

- The task description
- What model was recommended
- What model you think would be better
- Why (complexity, domain, edge case, etc.)

## Improving the Skill

### Test and iterate

1. Fork the repo
2. Copy `SKILL.md` to your Claude skills directory
3. Test it on your own tasks
4. Document what you find

### Suggest improvements

- Better decision framework wording?
- Missing domain examples?
- Edge cases not covered?
- Clearer explanations?

Submit a PR with your improvements. Include:
- What you changed and why
- Test cases that validate the improvement

## Adding Domain Examples

If you use this skill in a specific domain (web development, data engineering, DevOps, etc.), consider adding examples:

1. Create a section in `SKILL.md`
2. List Haiku/Sonnet/Opus use cases for that domain
3. Include concrete examples

## Code Style

- Keep explanations clear and beginner-friendly
- Use concrete examples, not abstract concepts
- Focus on *why* a model is better, not just when

## Questions?

Open an issue to discuss ideas before submitting a large change.
